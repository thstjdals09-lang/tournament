# Holdem TD — 홀덤 토너먼트 관리

레지스트레이션 · 테이블 관리 · 이벤트 관리 · 용지(참가확인증/상금바우처) 디자인을 한 화면에서. 모바일 우선, 설치/빌드 없음.

**배포:** https://thstjdals09-lang.github.io/tournament/

## 기능
- **등록**: 이벤트 선택 → 이름/바이인 입력 → 무작위 좌석 배정(🎲 다시 뽑기 / 직접 선택) → 등록 시 참가확인증 인쇄
- **테이블**: 새 테이블 오픈, 브레이크(플레이어 자동 재배치), 이동/자리 교환, 버스트아웃, 탈락 복구, 자동 밸런싱, 좌석 사용 체크박스
- **이벤트**: 한 현장 여러 이벤트. 이벤트별 테이블/참가자 완전 분리
- **용지**: 참가확인증·상금바우처 템플릿 편집(제목/부제/로고/문구/용지 80mm·A5·A4/표시 항목) + 실시간 미리보기, 바우처 발행 내역
- **되돌리기/다시실행** 50단계 (테이블 브레이크·생성·이동·탈락·등록 모두)
- 상단 바: 참가 / 탈락 / 남은 인원 / 테이블 수 / 밸런싱 필요 여부 / 브레이크 가능 테이블
- 데이터는 브라우저 localStorage 저장, JSON 내보내기/가져오기

## 실행
`index.html`을 브라우저에서 열거나 아무 정적 서버에 올리면 됩니다.
